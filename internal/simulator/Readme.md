# Math Simulator

Симулятор для тестирования математической модели слот-игры.

## Режимы работы

### 1. Simple Mode - Статистический анализ

**Для чего:** Проверка RTP, волатильности, математической модели и других метрик

Для выбора buyFeatures используйте параметр `-mod=...`.
Если нужен обычный режим без покупок, не указывайте этот параметр.

Возможные значения:
- `buyFs3s` - покупка фриспинов 3+ скаттера
- `buyFs4s` - покупка фриспинов 4+ скаттера
- `buyFs5s` - покупка фриспинов 5 скаттеров
- `buyDc` - каждый спин увеличен шанс выпадения скаттеров
- `buyEw` - каждый спин увеличин шанс выпадения вайлдов

**Запуск:**
```bash
go run cmd/main.go -spins=1000000 -rtp=96 -mod=buyFs3s
```

**Результат:** Детальный отчет с RTP, SD, VI, диапазонами выигрышей
```
out/v96/cost20/simple/seed123/2024-10-22.txt
```

---

### 2. Interactive Mode - Пошаговая отладка

**Для чего:** Отладка игровой логики, просмотр каждого спина

**Запуск:**

```bash
go run cmd/main.go -play=true -spins=10
```

**Результат:** Вывод в консоль с досками до/после каскадов

---

### 3. Player Mode - Симуляция игроков

**Для чего:** Анализ игрового опыта с разными балансами

**Запуск:**
```bash
go run cmd/main.go -playerMod=true -balance="10,20,30,40" -playersCount=100
```

**Результат:** Таблица с медианой спинов для каждого баланса
```
out/player_simulation/v96/cost20/simple/players100/seed123/2024-10-22.txt
```

```
BetValue: 20

Start balance:  | 10    | 20    | 30    | 40    |
Players count:  | 100   | 100   | 100   | 100   |
Median:         | 0.0   | 1.0   | 1.5   | 2.0   |
```

## Основные параметры

| Параметр        | Описание                    | Пример                |
|-----------------|-----------------------------|-----------------------|
| `-spins`        | Количество спинов           | `-spins=1000000`      |
| `-rtp`          | RTP версия (94/96/98)       | `-rtp=96`             |
| `-seed`         | Seed для воспроизводимости  | `-seed=12345`         |
| `-play`         | Включить interactive режим  | `-play=true`          |
| `-playerMod`    | Включить player stats режим | `-playerMod=true`     |
| `-balance`      | Балансы игроков в ставках   | `-balance="10,20,30"` |
| `-playersCount` | Игроков в группе            | `-playersCount=100`   |
| `-mod`          | Выбор бай фич               | `-mod=buyFs3s`        |

## Быстрые примеры

```bash
# Проверить RTP
go run cmd/main.go -spins=10000000 -rtp=96
```

```bash
# Отладить логику
go run cmd/main.go -play=true -spins=5
```

```bash
# Проанализировать длину сессий с разными стартовыми балансами (в ставках)
go run cmd/main.go -playerMod=true -balance="50,100,200" -playersCount=500
```

```bash
# Воспроизводимый результат по сиду
go run cmd/main.go -spins=1000000 -seed=42
```
